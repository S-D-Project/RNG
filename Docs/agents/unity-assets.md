# Unity 에셋 관리

씬, 프리팹, ScriptableObject, 임포트 설정과 에디터 도구를 변경할 때 적용한다.

## 에셋과 참조

- 에셋을 이동, 이름 변경 또는 삭제할 때 대응하는 `.meta`를 함께 처리한다.
- 기존 GUID와 씬, 프리팹, ScriptableObject 사이의 참조를 보존한다.
- 에셋의 역할과 사용처를 확인하고 기존 위치와 구성을 활용한다.
- 요청한 에셋과 설정에 필요한 변경만 수행하고, 변경 diff에서 참조와 직렬화 변경을 확인한다.

## 직렬화

- 직렬화 필드의 이름이나 타입을 변경하기 전에 저장된 에셋과 로딩 경로를 확인한다.
- 기존 데이터가 유지되도록 필드 이관과 에셋 갱신 방법을 함께 마련한다.
- `[SerializeReference]`로 저장된 클래스의 이름, namespace와 어셈블리를 변경할 때 저장된 타입 참조를 확인한다.
- 씬과 프리팹을 수정할 때 컴포넌트 연결, 활성 상태와 인스펙터 설정을 검증한다.
- Unity가 지원하는 편집 경로를 활용한다. 직렬화 파일을 직접 수정하는 작업은 해당 구조와 참조를 확인하고 결과를 검증한다.

## 에디터 도구

- 에디터 전용 코드는 `Editor/` 폴더 또는 적절한 에디터 전용 조건 안에 배치한다.
- 에셋 생성 도구는 입력값, 필수 참조, 저장 경로와 기존 에셋에 미치는 영향을 확인한다.
- 생성하거나 갱신한 에셋이 Registry와 실제 사용처에 연결되는지 확인한다.
- 아트 제작 기준은 [art.md](art.md), 검증 기준은 [verification.md](verification.md)를 함께 따른다.
