# 아트 제작

캐릭터, 적, 무기, 배경, 아이콘과 UI 이미지 등 아트 에셋의 제작과 수정에 적용한다. 사운드와 이펙트는 적용 범위에서 제외한다.

## 기준 확인

- 같은 용도의 기존 아트와 사용자가 승인한 레퍼런스를 먼저 확인한다.
- 시점, 비율, 실루엣, 팔레트, 명암과 외곽선의 기준을 맞춘다.
- 이미지 크기, 프레임 크기, 투명 영역과 출력 형식은 확인된 제작 규격을 따른다.
- 확정된 규격과 새로 결정해야 할 사항을 구분한다.

## 제작과 수정

- 같은 종류의 에셋 사이에서 스타일과 크기 기준을 유지한다.
- 실제 게임 표시 크기에서 대상의 형태와 용도가 식별되도록 제작한다.
- 플레이어, 적과 배경의 시각적 구분 및 아이콘의 가독성을 확인한다.
- 수정 시 요청 범위와 기존 에셋의 시각적 역할을 유지한다.

## 결과 확인

- 기존 동종 에셋과 함께 비교하여 시각적 일관성을 확인한다.
- 이미지와 프레임 규격, 투명 영역과 출력 형식을 확인한다.
- 실제 표시 크기에서 가독성과 의도한 형태를 확인한다.
- Unity 임포트와 참조 처리는 [unity-assets.md](unity-assets.md)를 따른다.
