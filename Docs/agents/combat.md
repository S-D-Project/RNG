# 전투 구현

플레이어, 적, 무기, 공격과 충돌 처리를 변경할 때 적용한다.

## 책임과 확장 위치

- 플레이어 입력과 이동은 `PlayerController`와 `MovementSystem`의 경로를 확인한다.
- `WeaponController`는 무기 상태와 발사 동작을 연결한다.
- `AttackRuntimeManager`는 공격의 생성, 이동, 수명, 충돌과 회수를 관리한다.
- `EnemyManager`는 적의 이동, 플레이어 접촉, 사망과 제거를 관리한다.
- 무기 확장은 타기팅, 발사 방식, 발사 패턴, 생성 위치, 이동, 명중 정책과 효과 중 책임이 맞는 구성에 둔다.
- 설정, 실행 구현과 `WeaponMaker`에서 사용하는 생성 경로를 함께 확인한다.

## 상태 소유권

- 무기 단위로 공유하는 설정과 공격별 상태를 구분한다.
- 공격의 수명, 명중 횟수와 개별 이동 상태는 해당 공격의 실행 상태에서 관리한다.
- 명중 정책의 이력과 무기 전체가 공유하는 이동 상태의 생성 단위를 확인한다.
- 공유 효과 객체에 공격별 상태가 섞이지 않도록 소유권을 유지한다.

## 검색과 충돌

- 적 검색은 `IEnemySpatialQuery`와 기존 공간 검색 경로를 활용한다.
- 타기팅 검색과 실제 겹침 판정에 필요한 반경을 구분한다.
- 이동, 공간 정보 갱신, 피해 적용과 사망 처리 순서를 확인한다.

## 풀링과 검증

- 풀에서 꺼낼 때 실행 상태를 초기화하고, 반환할 때 등록 정보와 점유 상태를 해제한다.
- 여러 공격과 적이 동시에 존재할 때 상태가 독립적으로 유지되는지 확인한다.
- 무기 조합과 풀 재사용을 실제 생성 경로에서 검증한다. 세부 기준은 [verification.md](verification.md)를 따른다.
