# 화면 표현과 입력

UI, 팝업, 로딩 화면과 카메라를 변경할 때 적용한다.

## UI 구성

- 기존 uGUI, TextMesh Pro와 공통 UI 컴포넌트를 활용한다.
- 표시 데이터와 실제 게임 상태 변경을 구분하고, 상태 변경은 해당 기능의 책임 소유자에게 전달한다.
- UI 프리팹의 참조, 레이아웃과 입력 연결을 함께 확인한다.
- 버튼 이벤트와 콜백은 화면의 활성 상태와 수명에 맞춰 연결하고 해제한다.

## 팝업

- 팝업 열기와 닫기는 `PopupManager`의 스택 관리 경로를 따른다.
- 최상단 팝업의 입력과 배경 가림 상태가 스택에 맞게 유지되도록 한다.
- 닫기 처리, 선택 콜백과 비동기 작업의 실행 순서를 확인한다.
- 팝업이 닫힐 때 보유한 콜백과 참조를 정리한다.

## 카메라와 검증

- 카메라는 추적 대상의 생성과 초기화 이후 연결한다.
- 추적 대상과 씬의 수명이 바뀔 때 참조와 갱신 상태를 확인한다.
- 실제 화면 크기에서 표시, 입력, 팝업 순서와 카메라 동작을 확인한다.
- 이미지 제작은 [art.md](art.md), 에셋 변경은 [unity-assets.md](unity-assets.md)를 따른다.
