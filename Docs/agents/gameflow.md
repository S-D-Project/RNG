# 게임 진행

부팅, 씬 전환, 스테이지와 웨이브 진행을 변경할 때 적용한다.

## 진입과 초기화

- 기본 진입 흐름은 `BootScene`에서 데이터를 로드한 뒤 `TitleScene`, `GameScene`으로 진행한다.
- `Bootstrap`과 `StageInitializer`의 초기화 순서 및 필수 참조를 확인한다.
- 시스템의 실행은 필요한 데이터와 의존성의 초기화가 완료된 뒤 시작한다.
- 씬 전환 시 유지되는 객체와 해당 씬에 속한 객체의 수명을 구분한다.

## 스테이지와 웨이브

- `StageDefinition`의 설정은 `WaveSpawnPlanBuilder`를 통해 실제 스폰 계획으로 변환한다.
- 스폰 계획에 맞춰 적 풀을 준비하고 `WaveManager`에서 실행한다.
- 웨이브 전환은 스폰 완료와 처치 수 또는 제한 시간 조건을 함께 확인한다.
- 마지막 웨이브 이후 남은 적과 스테이지 완료 조건을 확인한다.
- 테스트용 설정의 적용 범위를 명확히 하고, 게임 규칙 변경은 승인된 요구사항에 맞춘다.

## 실행 수명

- 코루틴과 비동기 작업의 시작, 종료와 취소를 해당 객체 및 씬의 수명에 맞춘다.
- 이벤트를 구독한 책임에서 구독 해제를 관리한다.
- 재진입과 재시작 시 진행 상태, 참조와 구독이 올바르게 초기화되는지 확인한다.
- 게임 진행 변경은 정상 씬 진입 경로를 통해 검증한다. 세부 기준은 [verification.md](verification.md)를 따른다.
