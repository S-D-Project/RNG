# {{PLAN 제목}}

새 ID는 `plan-YYYYMMDD-xxxxxxxx`, 파일명은 `<ID>-<주제>.md`로 정한다. 날짜·난수 생성과 승인 기준은 [plans.md](plans.md)를 따른다. 로컬 `source`에는 이 파일의 저장소 기준 경로를 기록한다.

새 로컬 PLAN은 `proposed`로 작성한다. 이슈 등록 시 머리말의 정보를 `PLAN metadata` YAML 코드 블록으로 옮기고 제목은 이슈 제목에 사용한다. 기록 등록은 기존 ID·상태를 유지하며, 완료 기록은 `completed`로 등록한다.

기존 PLAN의 실행 인계는 사용자 승인과 원본 전환을 마친 뒤 `ready`로 전환한다. 이관 후 `source`는 이슈 URL이며 로컬 파일은 당시 기록과 원본 링크를 보관한다.
